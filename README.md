# Free Custom QR Code Generator

Qraft is a free, privacy-friendly custom QR code generator built with React and Vite. Create branded QR codes with custom colors, patterns, logos, and 24 ready-made themes, then export them as PNG or SVG.

## Features

- Live QR code preview
- URL and text modes
- Custom colors and dot patterns
- Logo upload
- 24 ready-made templates
- PNG and SVG downloads
- Responsive design
- Browser-side QR generation
- SEO and AdSense-readiness foundations

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
